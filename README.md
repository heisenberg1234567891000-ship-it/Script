# Anime Abilities — Return By Death / Infinite Void / Hollow Purple

## Возвращение после смерти

**B** или кнопка со стрелкой сохраняет точку. После обычной игровой смерти и штатного возрождения сервер возвращает персонажа к сохранённой позиции и здоровью; клиент показывает часы с обратным ходом и новый цикл.

[Установка и ограничения Return By Death](RETURN_BY_DEATH.md).

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/heisenberg1234567891000-ship-it/Script/main/ReturnByDeath.client.lua", true))()
```

Полная способность требует [ReturnByDeath.server.lua](ReturnByDeath.server.lua) в `ServerScriptService` своего плейса. Без сервера доступны только визуальные эффекты. Работа во всех чужих режимах не обещается: их правила возрождения и состояния задаются владельцами. Карта, другие игроки и инвентарь не откатываются.

## Бесконечная пустота

Кинематографичная территория: крупный план аватара, чёрный сферический барьер, космический интерьер и потоки информации. **V** или кнопка **ПУСТОТА**: радиус **85 studs**, подготовка **3,2 с**, перегрузка **8 с**, перезарядка **28 с**.

[Установка, управление и настройки Infinite Void](INFINITE_VOID.md).

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/heisenberg1234567891000-ship-it/Script/main/InfiniteVoid.client.lua", true))()
```

Строка предназначена для клиентской среды с поддержкой `loadstring` и `game:HttpGet`. Для реальной заморозки игроков владелец плейса устанавливает [InfiniteVoid.server.lua](InfiniteVoid.server.lua) в `ServerScriptService`, а [InfiniteVoid.client.lua](InfiniteVoid.client.lua) — как LocalScript в `StarterPlayerScripts`. Без сервера работает визуальный просмотр.

Hollow Purple обновлён для совместной работы: перегрузка блокирует заряд, а камера уступает управление катсцене. Обнови обе его части при установке территории. В Roblox Studio этот комплект ещё не запускался; выполнены статические проверки и тесты логики на имитации API.

## Hollow Purple — 200% / MAXIMUM OUTPUT 4.0

Процедурный эффект для Roblox: слияние синей и красной энергии, крупный фиолетовый снаряд, молнии, шлейфы, обломки и ударные волны. «200%» — название режима, а не одинаковый множитель всех параметров.

Версия **MAXIMUM OUTPUT 4.0**: портрет аватара при слиянии, вращающиеся потоки энергии, объёмная аура, кометный хвост и многоступенчатый взрыв. **MAX включён по умолчанию**, в том числе на телефоне. Клавиша **K** или кнопка качества над PURPLE переключает MAX / HIGH / LOW; смена применяется после завершения активных эффектов. Ссылка загрузки прежняя. [Подробности обновления и настройки](HOLLOW_PURPLE_MAX.md).

## Загрузка по ссылке

Для клиентской среды, которая уже предоставляет `loadstring` и `game:HttpGet`:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/heisenberg1234567891000-ship-it/Script/main/HollowPurple.client.lua", true))()
```

В обычном **LocalScript Roblox Studio** такой способ запуска недоступен. Используй установку ниже. Ссылка загружает только клиентские эффекты; урон требует отдельного серверного скрипта, установленного владельцем плейса.

## Установка в Roblox Studio

1. Отключи старую версию Hollow Purple.
2. Создай **LocalScript** в `StarterPlayer → StarterPlayerScripts` и вставь содержимое [HollowPurple.client.lua](HollowPurple.client.lua).
3. Для урона и общего снаряда создай **Script** в `ServerScriptService` и вставь [HollowPurple.server.lua](HollowPurple.server.lua). Для перехода с предыдущей актуальной версии на MAX достаточно заменить клиентский файл; сервер в этом обновлении не менялся.
4. Нажми **Play** для проверки за персонажа.

Сервер создаёт `ISAGI_PurpleRemote` автоматически. Без него работает локальный визуальный предпросмотр без урона и воздействия на физику. С сервером запуск и попадание видят игроки с установленной клиентской частью; начальная зарядка остаётся локальной.

## Управление

- Удерживай **G** на ПК или кнопку **PURPLE** на телефоне, наведи камеру и отпусти.
- Полный заряд: **3,4 с**; слияние перед запуском: **1,1 с**; перезарядка: **6 с**.
- Отпускание раньше **0,3 с** или **Esc** отменяет заряд. Через 12 секунд удержания происходит автоматическое отпускание.
- Движение и обычное управление камерой сохраняются.

## Масштаб и настройки

При полном заряде диаметр тела снаряда — **12 studs**, внешней ауры — примерно **32 studs**; в MAX кометный хвост достигает **64 studs**, а внешнее эхо взрыва — **280 studs в диаметре**. Серверный радиус взрыва — **70 studs**, урон — **45**, дальность — **360 studs**. Обломки декоративные: карта не разрушается.

Параметры в таблице `CONFIG` клиентского файла:

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `Quality` | `"Max"` | MAX на всех устройствах. Доступны `"High"`, `"Low"`, `"Auto"`; K или кнопка меняет качество. Auto выбирает Low для сенсорных устройств, High для остальных. |
| `CameraShake` | `0.8` | Сила тряски; `0` отключает. |
| `FlashStrength` | `0.35` | Яркость вспышек; `0` отключает. |
| `FovKick` | `8` | Расширение обзора; `0` отключает. |
| `CinematicBars` | `true` | Чёрные полосы при зарядке. |
| `FaceCutin` | `true` | Портрет аватара при слиянии на High и Max. |
| `ProjectileDiameter` | `12` | Диаметр светящегося тела. |
| `VisualBlastRadius` | `70` | Радиус главной волны; радиус внешнего эха в MAX вдвое больше. |
| `MaxProjectiles` | `4` | Предел одновременно отображаемых снарядов. |
| `VisibleDistance` | `600` | Дистанция отсечения эффектов. |

Цвета находятся в таблице `C`. Звуковые поля пустые: при необходимости укажи свои доступные проекту `rbxassetid://...`.

При изменении `ChargeTime`, `MergeTime`, `MinCharge`, `Cooldown`, `Speed`, `MaxRange`, `ProjectileRadius`, `MuzzleHeight`, `MuzzleForward` или `MuzzleCorridorRadius` обновляй соответствующие значения в обоих файлах. Диаметр снаряда и радиус попадания согласованы как **12 / 6 studs**.

## Серверная часть

Сервер проверяет заряд, перезарядку, траекторию и попадания. Стены закрывают урон и силовое воздействие. Один взрыв наносит урон каждому Humanoid один раз. По умолчанию физика действует на живых персонажей; для свободного предмета добавь Boolean-атрибут `PurplePhysics = true` его детали или корневой детали сборки. Закреплённые детали не двигаются.

Способность действует на доступных Humanoid, кроме самого заклинателя. Для команд, безопасных зон и собственной системы боя добавь соответствующий фильтр перед `humanoid:TakeDamage(CONFIG.Damage)`. Большому снаряду нужно свободное место: стены, низкие потолки и тесные помещения могут препятствовать запуску.

## Проверка

Выполнены только статические проверки и проверка синтаксиса Lua 5.4-совместимого подмножества. **Roblox Studio здесь не запускался**; совместимость API, сетевую игру, изображение и FPS нужно проверить в своём проекте.

Проверь короткое нажатие и полный заряд, повторный запуск, стены и прицеливание вверх/вниз, Reset Character во время эффекта, отпускание пальца за кнопкой. Для серверной версии запусти два клиента и проверь общий снаряд и однократный урон.

Изучались изображения и отдельные кадры, игровые прогоны в этих плейсах не выполнялись. Чужие модели, музыка и видео в комплект не входят.
